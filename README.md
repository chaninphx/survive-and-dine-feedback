# Survive and Dine feedback

Submit a bug, suggest a feature, or vote for an idea. A free GitHub account is required to submit, comment, or vote. Anyone can read this board.

## Submit feedback

1. Search [existing requests](../../issues) first.
2. If your idea or bug exists, add a 👍 reaction to the original post instead of creating a duplicate.
3. Otherwise, [submit a bug report or feature request](../../issues/new/choose).

## Vote

Open a request, choose the reaction button on the original post, and select 👍. Each account gets one thumbs-up per request; click it again to remove your vote.

[See open requests with the most votes](https://github.com/chaninphx/survive-and-dine-feedback/issues?q=is%3Aissue%20is%3Aopen%20sort%3Areactions-%2B1-desc). Votes help prioritize improvements; they do not guarantee a feature or delivery date.

## Status

| Label | Meaning |
| --- | --- |
| New | Submitted and awaiting review |
| Planned | Accepted for future work |
| In progress | Being worked on |
| Done | Completed or resolved |

Bug reports use **bug**; suggestions use **enhancement**. The maintainer updates status labels and closes completed requests.

## Helpful reports

Describe one issue or idea per submission. Be kind and keep titles spoiler-free. This board is public: do not post league access codes, passwords, email addresses, or private picks. Remove private information from screenshots.

This repository is a feedback board, not the website source code.
